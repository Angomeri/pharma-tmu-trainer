**Интерактивный учебный тренажёр по фармакологии для подготовки к входному контролю, практическим занятиям и зачётам.**

## Возможности версии 0.5

| Раздел | Назначение |
| --- | --- |
| **Обзор** | Быстрый переход к заданиям и обзор учебной базы |
| **Рецептурная лаборатория** | Два этапа: определить препарат по показанию, затем написать рецепт и получить проверку |
| **Обучение и вопросы** | 104 варианта формулировок по четырём группам с выбором препарата и учебными пояснениями |
| **Каталог препаратов** | 32 рецептурных шаблона с характеристиками и образцами |
| **Мой прогресс** | Статистика ответов и рецептов, сохраняемая в браузере |

### Как проходит тренировка

1. Откройте **«Рецептурная лаборатория»**.
2. Выберите одну из четырёх групп: **холиномиметики, холиноблокаторы, адреномиметики или адреноблокаторы** (либо все группы).
3. Прочитайте задание, построенное по применению препарата, и введите его название.
4. Нажмите **«Проверить препарат»**. Приложение обозначит результат, покажет загаданный препарат, доступные наименования, механизм действия, группу и показания из учебной базы.
5. Перейдите к составлению рецепта для **того же препарата** — в том числе если при определении была допущена ошибка.
6. Введите рецепт на латинском языке и нажмите **«Проверить рецепт»**. Приложение укажет совпавшие поля, ошибки и пример прописи для сравнения.

Вопросы имеют несколько формулировок для одного препарата; при неоднозначном показании указывается дополнительный фармакологический контекст.

## Что проверяет программа

- Выбор препарата по условию вопроса и варианты названий, предусмотренные базой.
- Основные поля рецептурной прописи: препарат, лекарственная форма, числовая дозировка или концентрация, количество и путь введения — **в пределах того, что задано в проверенном шаблоне**.
- Ошибки, обнаруженные структурным анализатором, выделяются отдельно. Критические расхождения не должны компенсироваться правильностью других полей.

**Ограничения:** автоматическая оценка не является полноценной преподавательской экспертизой. Формулировки части вопросов не задают полный режим применения; полноту и корректность сигнатуры необходимо сверять вручную. В исходном наборе 29 рецептурных шаблонов отмечены `verified`, ещё 3 — `needs_review`; для трёх спорных шаблонов строгая количественная проверка выключена. Эти отметки унаследованы от предоставленной базы и не означают независимую научную проверку всех сведений.

## Источники и правила базы

Проект построен для работы с фиксированными учебными материалами, предоставленными для подготовки по фармакологии:

- **Г. З. Суфианова (ред.), «Фармакология», 2023** — основная учебная база классификаций и механизмов.
- **Д. А. Харкевич, «Фармакология», 13-е издание, 2021** — дополнительные фармакологические сведения.
- **Методические указания Тюменского ГМУ, 2024** — тематика занятий и требования к рецептуре.
- **«Таблицы по фарме.pdf»** — пользовательские рукописные таблицы, требующие проверки сомнительных записей.

Приложение не должно автоматически заменять эти источники новыми редакциями. Не все сведения в карточках полностью сверены со всеми указанными книгами. При противоречиях необходима дополнительная ручная проверка первоисточника.

> **Только для обучения.** Рецептурные примеры не предназначены для реального назначения лекарств пациентам.

## Запуск без установки

В репозитории откройте или скачайте файл **`index.html`**. Это самодостаточная веб-страница: учебные данные, стили и JavaScript версии 0.5 находятся внутри неё. Дополнительная сборка для просмотра не требуется.

## Как обновить приложение на GitHub Pages

1. Подготовьте новую версию `index.html`.
2. Перейдите к [редактированию index.html в ветке main](https://github.com/Angomeri/pharma-tmu-trainer/edit/main/index.html) или загрузите файл в корень репозитория с заменой прежнего.
3. Нажмите **Commit changes** и сохраните изменение в `main`.
4. Дождитесь зелёной отметки у **`pages build and deployment`** во вкладке [Actions](https://github.com/Angomeri/pharma-tmu-trainer/actions).
5. Откройте **[публичный сайт](https://angomeri.github.io/pharma-tmu-trainer/)**. Если видна старая версия, обновите страницу через `Ctrl + Shift + R`.

Для работы Pages должны быть настроены: **Settings → Pages → Deploy from a branch → `main` → `/(root)`**. Изменять эту настройку при каждом обновлении не требуется. Файл `.nojekyll` можно оставить.

## Как отредактировать этот README

1. Откройте [README.md в репозитории](https://github.com/Angomeri/pharma-tmu-trainer/blob/main/README.md).
2. Нажмите значок карандаша **Edit this file** (или откройте [прямую ссылку на редактор](https://github.com/Angomeri/pharma-tmu-trainer/edit/main/README.md)).
3. Замените содержимое текстом нового `README.md`.
4. Нажмите **Commit changes → Commit directly to the `main` branch → Commit changes**.
5. Обновите страницу репозитория: новый README появится под списком файлов.

**Важно:** изменение только `README.md` обновляет описание репозитория, **но не функциональность приложения**. Для изменений самого тренажёра обновляйте `index.html`.

## Структура репозитория

- `index.html` — автономная опубликованная версия **v0.5** (основная страница GitHub Pages).
- `.nojekyll` — настройка для статической публикации.
- `src/` — предыдущие структурированные данные и исходные модули, оставленные для разработки и дальнейшей сверки. Для запуска опубликованного `index.html` они не требуются.
- `tests/` — тесты предыдущей модульной структуры проекта.
- `.github/workflows/` — проверки кода; публикация осуществляется средствами GitHub Pages из `main`.
