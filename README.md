# PHARMA TMU Trainer v0.2

Локальный медицинский учебный тренажёр для подготовки по фармакологии ТМУ.

## Новое в версии 0.2

- **Банк вопросов:** 40 вопросов по четырём группам из предоставленного архива `PHARMA_TMU_Recepty_4_temy(1).zip`.
- **Справочник:** 32 рецептурных шаблона с механизмами, заметками и страницами источников.
- **Ввод ответа:** проверка выбранного препарата в зависимости от общей или уточнённой формулировки. Только буквальные названия и явно разрешённые архивом альтернативы считаются совпадением.
- **Образец прописи:** доступен после ответа; собственная пропись сверяется вручную. Автоматическая оценка полного рецепта для всех 40 новых заданий **запрещена схемой исходного архива** (`strict_full_recipe_autograding:false`).
- **Статусы:** 37 вопросов `verified`, 3 `needs_review` (статусы сохранены как были в архиве). Сомнительные вопросы не проверяются автоматически. Три из 32 шаблонов также имеют статус `needs_review`.
- **История изучения:** сохраняется локально в `localStorage`.
- **Сохранено:** 10 базовых упражнений редактора рецептов из v0.1, детерминированная проверка доз, концентраций, форм, латинских названий.

## Запуск

Откройте `PHARMA_TMU_Trainer_v0.2.html` двойным щелчком — весь контент и JavaScript внутри одного файла.

Для разработки откройте папку проекта через статический сервер:

```bash
python3 -m http.server 4173
```

Перейдите на `http://127.0.0.1:4173/`.

## Тесты

```bash
npm test
```

Тесты проверяют данные и связи 40 вопросов, 32 шаблонов, корректное сопоставление названий и сохранение ограничений на проверку рецептурных прописей, а также регрессию v0.1.

## Публикация GitHub Pages — один раз

Ветка `main` уже содержит автономную страницу `index.html` и данные. Для публикации **не нужна сборка**.

1. Откройте **Settings → Pages** в репозитории.
2. **Build and deployment → Source → Deploy from a branch**.
3. **Branch → main**, **Folder → /(root)**, нажмите **Save**.
4. Дождитесь успешного статуса `pages build and deployment`.
5. Откройте https://angomeri.github.io/pharma-tmu-trainer/.

Отдельный файл `.github/workflows/pages.yml` выполняет только тесты и не отвечает за публикацию. Это устранение ошибки `Get Pages site failed — Not Found` в Actions, которая была вызвана тем, что GitHub Pages не был активирован.

## Архитектура публикации

Загрузите содержимое этой папки в собственный репозиторий GitHub. После однократного включения GitHub Pages публикация выполняется автоматически из ветки main.

## Файлы

- `index.html` — входная страница.
- `src/main.js` — пользовательский интерфейс и состояние.
- `src/data.js` — 10 предыдущих рецептурных упражнений.
- `src/validator.js` — строгое сравнение 10 упражнений.
- `src/pharma_rx_bank.json` — **исходная база**, импортированная из архива пользователя без изменения записей.
- `src/bank-data.js` — база в формате JS для работы без сервера.
- `src/bank-eval.js` — сопоставление препарата с эталонами, без автоматической проверки рецептурной строки.
- `src/styles.css` — визуальная система.
- `tests/` — тесты на Node.js.

## Учебные ограничения

Содержание предназначено для учебных целей, **не для назначения пациентам**. Исходная база имеет свои нерешённые вопросы: три задания и три рецептурных шаблона нуждаются в сверке с учебной литературой. Статус `verified` — это статус из предоставленного файла, а не новая независимая проверка автора приложения. Рукописные таблицы могут содержать ошибки или нечёткие значения.
