# PHARMA TMU — рецептурная мастерская

Учебное приложение по четырём группам: холиномиметики, холиноблокаторы, адреномиметики, адреноблокаторы.

## Что изменилось

- Ванильная и коричневая палитра, адаптивная навигация, SVG-иконка.
- Единый переход «показание → выбор препарата → написание рецепта» в лаборатории и обучении.
- 115 формулировок для 32 рецептурных шаблонов (30 препаратов). Есть новые показания и переформулировки исходных вопросов.
- После правильного и ошибочного ответа открывается карточка препарата и редактор для исходно загаданного средства.
- Поиск и фильтры четырёх групп, механизм, названия, доступные показания и ссылки на страницы источников.
- Проверка конкретного учебного образца: латинское название и соль, форма, концентрация, объём, количество, оформление и наличие сигнатуры. Поддерживаются десятичная запятая и точка, мг/мкг, некоторые сокращения.
- Статистика старой опубликованной версии сохраняется.

## Применить изменения через GitHub

1. Откройте подготовленный pull request в `Angomeri/pharma-tmu-trainer`.
2. На вкладке **Files changed** посмотрите изменения; на вкладке **Checks** дождитесь успешных тестов.
3. Нажмите **Merge pull request → Confirm merge**. Это перенесёт подготовленные файлы в `main`.
4. В **Settings → Pages** оставьте **Deploy from a branch**, **main**, **/(root)**. Повторная настройка обычно не нужна.
5. Дождитесь завершения **pages build and deployment** во вкладке **Actions**.
6. Откройте https://angomeri.github.io/pharma-tmu-trainer/ и обновите страницу с очисткой кэша (`Ctrl+F5`, на macOS `Cmd+Shift+R`).

Сборка и установка зависимостей не нужны. `index.html` теперь загружает JS-модуль и CSS из `src`; переносить только HTML недостаточно. Для ручного переноса возьмите все изменённые файлы из PR, сохранив пути.

## Локальный запуск

```bash
python3 -m http.server 4173
# Открыть http://127.0.0.1:4173/
npm test
```

Открытие HTML двойным щелчком не поддерживается: ES-модулям нужен HTTP-сервер.

## Источники и пределы проверки

Исходный банк `src/pharma_rx_bank.json` и его JS-копия сохранены без изменения статусов. Дополнения находятся в `src/training-data.js`; интерфейс — `src/trainer.js`; проверка — `src/training-checker.js`.

Использованы предоставленные материалы: Суфианова (2023), Харкевич (2021), рукописные таблицы и методические указания ТМУ (2024). Добавленные холинергические показания сверены по доступным извлечённым страницам Суфиановой 54–72; аритмии и названия β-блокаторов — по Харкевичу, с. 153. Классификация адренергического блока по Суфиановой отдельно не сверена и так помечена в интерфейсе. Перечни имён и показаний ограничены доступными фрагментами, а не объявлены полными регистрационными инструкциями.

Три образца (глазной прозерин, дипироксим, сальметерол) имеют нерешённые расхождения в дозировках: для них автоматическая проверка отключена. Образцы с неполной сигнатурой требуют ручной сверки даже при совпадении формальных элементов. Иная формулировка сигнатуры направляется на сверку, не признаётся автоматически неправильной или правильной. Валидатор сравнивает с заданным образцом, не является универсальным анализатором рецептов или назначения лечения. Он не оценивает свободный подбор схемы по одному показанию.

Для разнообразных показаний после идентификации даётся отдельное упражнение по фиксированной форме того же препарата; сигнатура образца не подменяет схему лечения исходной ситуации. Устаревшие учебные показания сохранены как учебные.

Старые `src/main.js`, `data.js`, `validator.js` оставлены для совместимости и регрессионных тестов; опубликованная страница их больше не подключает.
