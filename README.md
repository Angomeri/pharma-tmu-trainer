# PHARMA TMU — установка новой версии

Версия от 16 октября 2026 года. Дополненная версия: классификация и карточки по Суфиановой, рецепт с нуля без подсказок. Эта редакция новее первоначального PR №1. Архив содержит полный комплект файлов приложения; этот README дополнен инструкцией для ручной установки.

Репозиторий: https://github.com/Angomeri/pharma-tmu-trainer
Сайт: https://angomeri.github.io/pharma-tmu-trainer/

## Что есть в новой версии

- Ванильно-коричневое оформление и иконка сайта.
- Два этапа: определить препарат по показанию → написать рецепт на исходно загаданный препарат.
- После ответа — результат ✓/✕, названия, действующее вещество, доступные торговые марки, группа, механизм и показания.
- Выбор холиномиметиков, холиноблокаторов, адреномиметиков или адреноблокаторов.
- 115 формулировок и 32 рецептурных шаблона: сохранены 104 вопроса из обновлённого main и добавлены 11 дополнительных.
- Проверка фиксированного рецептурного условия и разбор расхождений.
- Сохранение локальной статистики ранее опубликованной версии.

## Способ 1. Заменить файлы через сайт GitHub

1. Скачайте `PHARMA_TMU_Sufianova_no_hints.zip` на компьютер.
2. В Windows щёлкните по ZIP правой кнопкой мыши → «Извлечь всё…».
3. Откройте извлечённую папку. В ней должны лежать `index.html`, `favicon.svg`, `README.md`, `package.json`, папки `src`, `tests` и `.github`.
4. Для резервной копии откройте свой репозиторий → зелёная кнопка **Code → Download ZIP**. Сохраните эту копию отдельно.
5. Откройте https://github.com/Angomeri/pharma-tmu-trainer и выберите ветку **main** над списком файлов.
6. Нажмите **Add file → Upload files**.
7. Перетащите в поле загрузки СОДЕРЖИМОЕ извлечённой папки: файлы и папки `src`, `tests`, `.github`. Не перетаскивайте сам ZIP или внешнюю папку `PHARMA_TMU_latest`.
8. Проверьте пути в списке загрузки: `index.html` должен быть в корне, а `trainer.js` — по пути `src/trainer.js`. Не должно быть лишнего префикса `PHARMA_TMU_latest/`.
9. В поле сообщения коммита напишите: `Update PHARMA TMU: vanilla design and prescription trainer`.
10. Выберите **Commit directly to the main branch** и нажмите **Commit changes**. Если прямое сохранение запрещено настройками репозитория, выберите создание ветки, затем откройте и объедините pull request.
11. Файлы по совпадающим путям обновятся, новые добавятся. Удалять сам репозиторий, его историю или настройки не нужно. Старые файлы в `src` оставлены для совместимости и тестов; приложение подключает новый `src/trainer.js`.
12. Откройте **Settings → Pages**. При публикации из ветки параметры должны быть: **Deploy from a branch → main → /(root)**. Если они уже выставлены, ничего менять не нужно.
13. Во вкладке **Actions** дождитесь успешного завершения задания **pages build and deployment**. Отдельное задание **Test PHARMA TMU** проверяет тесты, но не публикует сайт.
14. Откройте https://angomeri.github.io/pharma-tmu-trainer/ и нажмите **Ctrl+F5**. На macOS — **Cmd+Shift+R**.

ВАЖНО: загрузка ZIP как одного файла не обновляет приложение. GitHub не распаковывает загруженный архив автоматически. Перенос одного `index.html` также недостаточен — ему нужны файлы из `src` и `favicon.svg`.

Если папка `.github` не видна, включите отображение скрытых элементов. Для работы страницы важнее всего `index.html`, `favicon.svg` и вся папка `src`; `.github` содержит настройку автоматических тестов.

## Если версия на сайте не изменилась

- Проверьте, что файлы загружены именно в `main`, а не в другую ветку.
- Убедитесь, что `index.html` находится в корне репозитория.
- Убедитесь, что опубликована последняя версия: дождитесь завершения `pages build and deployment`.
- Обновите страницу без кэша или откройте в приватном окне.
- При пустой странице проверьте наличие `src/trainer.js`, `src/training-data.js`, `src/training-checker.js`, `src/bank-data.js`, `src/bank-eval.js`, `src/vanilla.css`.

## Локальный запуск — необязательно

Сборка не нужна. Для локального запуска требуется Python:

```bash
python -m http.server 4173
```

Команда выполняется в папке с `index.html`. Затем откройте http://localhost:4173/.
Открытие HTML двойным щелчком не поддерживается: JavaScript-модулям нужен HTTP-сервер.

Для тестов при установленном Node.js:

```bash
npm test
```

## Учебная база и ограничения

Источники фиксированы: Суфианова, 2023; Харкевич, 13-е издание, 2021; таблицы препаратов; методические указания ТМУ, 2024. Исходные данные и спорные статусы сохранены. Дополнения расположены в `src/training-data.js`.

- Глазной прозерин, дипироксим и сальметерол требуют сверки количественных эталонов. Для них автоматическая проверка отключена.
- Рецепт пишется с пустого поля. Форма, дозировка, количество, путь введения и сигнатура заранее не раскрываются. Образец доступен после непустой попытки и нажатия «Проверить рецепт».
- Проверяется совпадение с сохранённым учебным образцом. Альтернативные допустимые формы, количество и схемы требуют ручной сверки; расхождение с образцом не равнозначно ошибке.
- Неполная или иначе сформулированная сигнатура требует ручной сверки и не признаётся автоматически ошибочной или верной.
- Сигнатура сохранённого образца не переносится автоматически на каждое исходное показание.
- Имена и показания ограничены доступными фрагментами учебников. Полнота перечня торговых марок не подтверждена.
- Основной источник теории — Суфианова, 2023. Адренергическая классификация сверена по с. 87 и 99, карточки дополнены по с. 87–112: названия, механизмы, показания. Харкевич и таблицы остаются дополнительными источниками рецептуры.
- Материал предназначен для учебной рецептуры, а не назначения лечения.

В предыдущем прогоне прошли 42 теста; после включения обновления main — 6 целевых тестов. Браузерная визуальная проверка не выполнена из-за отсутствия браузера и ошибки его загрузки. При подготовке этого архива проверены комплектность и целостность ZIP; повторный прогон приложения не выполнялся.
